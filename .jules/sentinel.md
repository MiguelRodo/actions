## 2024-06-25 - [CRITICAL] Prevent JSON Injection via unescaped variables
**Vulnerability:** Bash variables were being interpolated directly into JSON strings using string manipulation (`echo` + `sed`). If the input variables contained double quotes or unescaped characters, this would result in malformed JSON or allow JSON injection attacks against the configuration file being built.
**Learning:** Using raw string manipulation (like `sed`) to construct JSON from dynamic inputs in bash scripts is fundamentally unsafe. In bash context, the only robust way to properly escape arbitrary strings for JSON is using jq.
**Prevention:** Always use `jq -R` with `--arg` or `--argjson` when dealing with raw string conversion to JSON objects/arrays. For splitting delimited strings safely into JSON arrays, use `echo "$INPUT" | jq -R -c '[splits("[,;]")] | map(select(length > 0))'`.
